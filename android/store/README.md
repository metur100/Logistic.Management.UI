## Language setup in Play Console

- Default store listing: **Croatian (hr)**.
- Additional store listing: **English (en)**.
- App UI: **Bosnian + English** (by request); the Croatian listing uses the
  Bosnian UI screenshots in `screenshots-bs/`.
- App icon and feature graphic are **global**; Play Console only accepts one of
  each. Use `feature-graphic-hr-1024x500.png` if the Croatian listing is the
  primary one, or `feature-graphic-1024x500.png` for the English version.
- Both feature graphics are 1024×500 and meet the Play Store requirement.

Screenshots were captured from the live app at
`https://logistic-management-ui.pages.dev` on 21 October 2026 with a
432 × 768 CSS viewport at 2.5× density (1080 × 1920).
